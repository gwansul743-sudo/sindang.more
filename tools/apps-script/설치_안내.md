# 구글폼 → 지도 주민 연결 (한 번만, 15분)

응답이 들어오면 몇 초 안에 지도·전시 화면에 빨간 세모 주민이 걸어 들어온다. 대본은 앱이 만든다(`src/features/villagers/formScript.ts`).

## 1. Supabase — SQL 한 번
Supabase → SQL Editor → `supabase/form_pipeline.sql` 내용을 붙여 넣고 Run. (실시간 켜기 + 색인. 여러 번 실행해도 괜찮다)

## 2. Supabase — 비밀 키 복사
Project Settings → API Keys → **Secret key**(`sb_secret_…`) 복사. 저장소·채팅·.env 에 붙이지 않는다. 바로 3-③에만.

## 3. 응답 시트에 Apps Script 붙이기
① 응답 시트 '다산로44길(신당오길) 상인 설문(응답)' 열기 → 확장 프로그램 → Apps Script
② 기본 `Code.gs` 내용을 지우고 `tools/apps-script/form_to_supabase.gs` 전체를 붙여 넣고 저장(💾)
③ 왼쪽 ⚙ 프로젝트 설정 → 맨 아래 스크립트 속성 → 속성 추가 세 줄
   - `SUPABASE_URL` = `.env` 의 `VITE_SUPABASE_URL` 값
   - `SUPABASE_KEY` = 2에서 복사한 Secret key
   - `AUTO_PUBLISH` = `true` (승인 뒤에 띄우고 싶으면 `false`)
   - (선택) `OPENAI_KEY` = OpenAI API 키 — 자유서술(문8-1·문9-1)을 사장님 말투로 다듬는다. 없으면 원문 그대로 규칙만 쓴다
   - (선택) `OPENAI_MODEL` = 기본 `gpt-6-luna`(2026-10 기준 가장 싼 모델). 바꿀 때만
④ 편집기 위쪽 함수 목록에서 `checkConnection` 선택 → 실행 → 권한 허용(처음 한 번) → 실행 로그에 `200 []` 이 보이면 연결 OK
⑤ 왼쪽 ⏰ 트리거 → 트리거 추가 → 함수 `onFormSubmit` · 이벤트 소스 **스프레드시트에서** · 이벤트 유형 **양식 제출 시** → 저장

## 4. 시험
폼을 미리보기로 열어 SQ2(업종)·문30 정도와 파트 A 몇 칸을 채워 제출 → 지도(배포 주소)에서 20초 안에 빨간 세모 주민 등장 → 마우스 올리기·클릭으로 대본 확인.
시험 응답 지우기: Supabase → Table Editor → characters 에서 그 줄 status 를 `hidden` (또는 줄 삭제).

## 운영
- 내리기: characters.status = `hidden` → 몇 초 안에 사라짐.
- 대본 손보기: interviews.summary_md 에 `{"name":"밥집 사장님","hook":"…","pages":["…","…","…"]}` → 규칙 대신 이것을 씀.
- 트리거를 늦게 달았거나 실패한 응답: Apps Script 에서 `sendMissing` 실행(보낸 줄은 건너뜀).
- 화면엔 동시에 6명까지. 7번째가 오면 가장 먼저 온 사람이 퇴장(인터뷰는 DB 에 남음).

## 보내는 것 / 안 보내는 것
보냄: 타임스탬프, SQ1(연차), SQ2(업종), 문1, 문8·8-1, 문9·9-1, 문11-1, 문30, 파트 A(상인회·재개발·건물 문장 제외).
안 보냄: SQ3(상호 — 폼에 익명 처리 안내), SQ4~6, 문2~7, 문10, 문12~29, 문31~43, 연락처. `interviews` 는 공개 읽기 표라 처음부터 올리지 않는다.

## 자유서술 AI 정돈 (선택)
- 하는 일: 문8-1·문9-1 글을 해요체 1~2문장·50자 안팎으로 다듬어 원문과 함께 보낸다(`AI 정돈|문8-1`). 앱은 정돈본을 먼저 쓴다.
- 안전장치: 원문에 없는 숫자가 생기거나, 60자·원문+15자를 넘거나, 욕설이 있으면 정돈본을 버리고 원문 규칙으로. AI 가 비방·광고·지시문으로 보면 `(빼기)` → 그 장을 뺀다. AI 가 실패해도 응답은 그대로 올라간다.
- 공개 표에 올리기 전에 자유서술의 전화·링크·메일은 `[가림]`으로 바꾼다(AI 에도 가린 글만 간다). `[가림]`이 남은 원문은 대본에서 뺀다.
- 시험: 스크립트 속성에 `OPENAI_KEY`를 넣고 `testTidy` 실행 → 실행 로그에 원문 → 정돈본. Supabase 에는 아무것도 쓰지 않는다.
- 비용: 응답 1건에 AI 호출 최대 2번. 건당 1원 미만.
